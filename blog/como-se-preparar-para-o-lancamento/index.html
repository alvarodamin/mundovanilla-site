Como se preparar para o lançamento: instale o client

O Mundo Vanilla é um servidor de Minecraft Java Edition 26.2 com Fabric. Boa parte do que torna o servidor diferente (menu, loja, leilão, trocas, pets) é desenhada na sua tela por um mod, o Mundo Vanilla Client. Por isso ele é obrigatório.

O que instalar

  • Fabric Loader, o carregador de mods.
  • Fabric API, a biblioteca base.
  • Mundo Vanilla API, a biblioteca do nosso client.
  • Mundo Vanilla Client, o mod principal.

O jeito mais simples é pelo CurseForge, que instala tudo sozinho. Se preferir, a página de Download tem os arquivos para baixar direto e o passo a passo.

Fui barrado ao entrar

O servidor só deixa entrar quem está com o client na versão certa. Se a conexão for recusada, baixe a versão mais recente na página de Download, apague os arquivos antigos da pasta mods e tente de novo.

Precisa de ajuda? O suporte de instalação fica no Discord.

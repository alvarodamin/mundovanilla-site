Mundo Vanilla

Download

Para jogar no Mundo Vanilla você precisa instalar os mods obrigatórios do servidor. Escolha baixar o modpack pronto no CurseForge ou pegar os arquivos direto, um por um.

Recomendado

Pelo CurseForge

Pra obter o modpack basta baixar pelo CurseForge. É a forma mais simples: o CurseForge App instala automaticamente todos os mods obrigatórios e a versão certa do Fabric no seu launcher.

  • Um único pacote, sem montar nada na mão
  • Instalação automática dos mods e do Fabric
  • Atualizações futuras ficam na mesma página
Baixar no CurseForge
Manual

Download direto

Se quiser baixar direto os mods, são 3 arquivos obrigatórios (incluindo a biblioteca base do Fabric). Baixe todos e coloque na pasta mods do seu launcher com Fabric.

  • Fabric API

    Biblioteca base do Fabric, exigida pelos outros dois mods.

    v0.153.0

  • Mundo Vanilla API

    Biblioteca de suporte exigida pelo Client.

    v0.1.0

  • Mundo Vanilla Client

    Mod principal com as mecânicas do Mundo Vanilla.

    v0.1.0

Os três arquivos são obrigatórios e precisam estar juntos na pasta mods para o jogo conectar no servidor.

Depois de baixar

3 passos até jogar

1

Instale o Fabric Loader

O Mundo Vanilla roda em Minecraft 26.2 Java Edition (original, não é Bedrock) com Fabric Loader. Instale o Fabric antes de adicionar os mods.

2

Adicione os mods

Pelo CurseForge App os mods entram sozinhos. No download direto, coloque os três arquivos .jar na pasta mods do seu launcher.

3

Conecte no servidor

Abra o Minecraft, adicione o IP play.mundovanilla.com.br e entre no beta aberto.

Deu algum problema na instalação? A comunidade e o suporte oficial do Mundo Vanilla ficam no Discord.
